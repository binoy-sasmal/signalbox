### what this is ###
Review 7 F4: the image-refresh command in variables.tf carried embedded '#'
characters mid-line, so a shell would not see the flags after the first one.
The fix splits it across comment lines. This file is the fix verified by
running it through a shell, not by reading it.

Method: the six comment lines are extracted from variables.tf by program,
their leading '#' is stripped, and the result is sourced with 'oci' replaced
by a shim that prints the argv the shell actually built. No OCI call is made
and no OCI CLI is installed here; what is under test is the shell's
tokenisation of the comment, which is the only thing that was broken.
